# Verdensmakt 2026

Single player grand strategy browser game set in 2026, inspired by Hearts of Iron IV, Millennium Dawn and Europa Universalis V.
Pure HTML/CSS/JavaScript – no build step. Open `index.html` to play.

- Statsbudsjett med skatt, utgiftsposter, statsgjeld, kredittvurdering og renter
- Interessegrupper og samfunnsverdi-glidere som styrer stabiliteten
- Teknologitre, industri, militærproduksjon, krig og diplomati

Flagg lastes fra [flagcdn.com](https://flagcdn.com). Kart: Natural Earth (offentlig eiendom).
